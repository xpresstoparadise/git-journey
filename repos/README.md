# repos/

Положите сюда клоны репозиториев команды — по одному в папку:

    git clone https://gitlab.example/team/project-a.git
    git clone https://gitlab.example/team/project-b.git

Затем из корня проекта: `python fetch_local.py` (или `start-local.cmd` / `start-local.sh`).
Содержимое папки в git не попадает.
